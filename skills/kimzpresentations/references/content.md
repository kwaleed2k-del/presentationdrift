# Content & story rules

A sick deck is a good story with great motion — motion can't rescue a weak story.

## Writing
- **Bullets are one sentence.** 2–4 per slide. Lead with the outcome ("Live in minutes, no redeploy"), not the mechanism.
- **Headlines are two beats:** a plain line + an accent line (`title` + `accent`): "Any AI model." / "Live in minutes."
- **One idea per slide.** If you need "and", it's two slides. Text-heavy slides get cut first in feedback.
- **Name things the audience knows.** Technical terms (TDD, GOP, RTL) need a plain-word version for mixed audiences.

## Facts
- Never invent capabilities, numbers, quotes, customers, or names. If content is missing, use an obvious placeholder (`Example quote`, `illustrative data`) and tell the user.
- Prefer real artefacts: screenshots, the product's own taglines, real videos, real photos (with permission).
- Mock UIs (LiveTableSlide, hand-built cards) are fine when labelled — mask users (`n•••@gmail.com`).
- Weak or embarrassing real numbers: leave them out. Show structure (how a score is weighted) instead of a tiny count.

## Story shapes
**Pitch:** Title → Problem (Statement) → Solution (Split) → How (Process) → Product (RingCarousel/Screenshot) → Traction (Stats) → Why us (Compare) → Ask (Bento) → Finale.
**Product launch:** Title → Why (Statement) → Meet it (Split + toasts) → Features (Bento) → Watch it work (LiveTable/VideoWall) → Before/after (Compare) → Finale.
**Report/QBR:** Title → Agenda (steps) → Headline numbers (Stats) → Trend (Chart) → What changed (Compare) → Plan (Split) → Finale.
**Tech talk:** Title+terminal → Stack (Orbit) → Loop (Terminal) → Pipeline (Process) → Demo (Screenshot/VideoWall) → Journey → Finale.
**"How I work" / personal showcase:** Title+terminal → Who I am (Orbit with photo) → Wall of work → Tools (custom beams/Orbit) → each product: cover → flow → hero features (Admin mock, Arena race, Screenshot) → films (VideoWall) → thanks (one PeopleSlide per person, leader last as a Journey) → Finale with `car`.
**Thank-you section:** one person (or pair) per slide, big straight photos, 2–4 stickers on the edges, the leader last.

## Section covers
Before a new product/chapter, add a cover (TitleSlide with `bg` + chips listing what's coming). It resets attention and makes the deck feel produced.

## Rhythm
- Alternate dense and airy slides. After two information slides, give a statement or a visual.
- Use `steps` for things the speaker narrates (carousels, wizards, agendas) so the presenter controls pace with →.
- 20–30 slides for a 20-minute talk. Cut ruthlessly.
